## Cómo hacerlas útiles

1. Muestra solo el área necesaria, con texto legible.
2. Añade como máximo dos o tres flechas o números por imagen.
3. Oculta claves reales, rutas personales y conversaciones ajenas.
4. Usa PNG y captura la interfaz que realmente estás documentando.
5. Añade texto alternativo describiendo qué debe aprender el lector.

Cuando exista cada archivo, reemplaza su placeholder en el README por este patrón, cambiando nombre y descripción:

```markdown
![Cline conectado a una API local: Base URL y Model ID](assets/04-cline-api-local.png)

*Conecta Cline a tu servidor local.*
```

Desde un documento dentro de `docs/`, la ruta debe empezar por `../assets/`.
